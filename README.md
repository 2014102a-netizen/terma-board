# ТЕРМА · Рабочая группа

Мобильная доска рабочей группы проекта ТЕРМА: кто что обещал на встрече, что просрочено, кто кого ждёт, какие решения приняты и какие вопросы открыты.

Источник один — Google Таблица «ТЕРМА — рабочая группа: задачи и обещания». Приложение только читает её. Вход по общему паролю группы, вход живёт 90 дней на устройстве.

## Как это работает

```
Встреча → протокол → строки в таблице → Apps Script (проверяет пароль) → эта страница
```

- Страница на GitHub Pages (`docs/`) не содержит ни данных, ни пароля.
- Apps Script привязан к таблице, запускается от имени владельца и отдаёт данные только после входа.
- После входа доска показывает телефон и Telegram участника в его карточке. Колонка «Почта» наружу не отдаётся никогда.
- Изменения в таблице видны примерно через 30 секунд после обновления страницы.

## Правила таблицы

1. **Сквозная нумерация задач.** Новая встреча продолжает номера (31, 32…), а не начинает с 1.
2. **Одна задача — одна строка.** Перенос: меняем «Срок» и «Статус», новую строку не заводим.
3. **Статусы:** Открыт / В работе / Выполнено / Перенос / Снято. Для решений: Принято / Предварительно.
4. **«Зависит от»:** «Задача 3» или «Задачи 3, 12, 11» — по этим номерам строятся связи «кто кого ждёт».
5. **Даты** в формате 09.11.2026. Встречи — по понедельникам.
6. Колонки можно переставлять, их имена менять нельзя (сервер ищет колонки по заголовкам).

## Запуск (один раз, делает владелец таблицы)

1. Открыть таблицу → «Расширения → Apps Script». Удалить пример, вставить `apps-script/Code.gs`, сохранить.
2. «Настройки проекта» (шестерёнка) → «Свойства скрипта» → добавить `GROUP_PASSWORD` = пароль группы. По желанию `SESSION_SALT` = любая длинная строка.
3. Выбрать функцию `checkSetup` → «Выполнить» → дать разрешения. В журнале должно быть число задач, решений и вопросов.
4. «Развернуть → Новое развертывание → Веб-приложение»: запуск от моего имени, доступ «Все». Скопировать URL, заканчивающийся на `/exec`.
5. Вписать URL в `public/config.js` (`window.TERMA_API`), выполнить `npm run pages`, закоммитить.
6. GitHub → Settings → Pages → Branch `main`, папка `/docs`.

Смена пароля: поменять `GROUP_PASSWORD` в свойствах скрипта. Все старые входы сразу закрываются.

После правки `Code.gs`: «Развернуть → Управление развертываниями → Изменить → Новая версия». URL остаётся прежним.

## Рассылка задач по почте

`apps-script/Mailer.gs` — второй файл того же проекта Apps Script. Каждый участник с адресом в колонке «Почта» вкладки «Участники» получает письмо со своими открытыми задачами: просрочено, к встрече, позже, без срока, кто ждёт его результата и кого ждёт он. Google-аккаунт получателю не нужен.

- `previewDigest` — все письма приходят только владельцу таблицы, в теме указано, кому ушло бы письмо.
- `sendDigest` — настоящая рассылка с почты владельца.
- Если скрипт привязан к таблице, в ней появляется меню «ТЕРМА» с этими двумя пунктами.
- Короткое имя в задаче («Александр») засчитывается, только если среди участников с почтой оно подходит одному человеку.

## Telegram-бот

`apps-script/Bot.gs` — третий файл того же проекта. Токен лежит в свойстве скрипта `TELEGRAM_TOKEN`, в коде его нет.

1. Написать боту `/start` → запустить `connectMe` (бот запомнит личный чат).
2. `testBot` — прислать все сообщения сразу и посмотреть.
3. `installBotSchedule` — включить расписание: пт 17:00 «К встрече», пн 9:00 повестка, будни 9:00 сроки (только если есть).
4. Позже: добавить бота в группу, написать там сообщение → `connectGroup`.
5. `stopBot` — выключить расписание.

Если в «Задачах» появится колонка «Тема», пятничное сообщение группируется по темам, иначе по людям. Ник из колонки «Telegram» в «Участниках» превращается в упоминание.

## Разработка

```bash
npm ci
npm test                      # сервер и логика доски
python3 tools/fixture_from_export.py <выгрузка таблицы>   # local/tables.json, в git не попадает
npm run dev:api               # локальный API, пароль dev-password
npm run dev                   # интерфейс; в public/config.js временно http://127.0.0.1:8787
npm run pages                 # сборка в docs/
```
