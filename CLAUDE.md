# ТЕРМА · Рабочая группа — правила для агента

Мобильная доска задач рабочей группы проекта ТЕРМА (термальный комплекс, Шушары). Владелец — Андрей Минеев. Язык интерфейса и документации — русский.

## Устройство

- React 19 + Vite, без CSS-фреймворка, стили в `src/index.css` через CSS-переменные.
- Сборка в `docs/` (`npm run pages`), GitHub Pages: `main` → `/docs`.
- Данные: Google Таблица `1W2cPtOLtnWWpU8ivv61oOKSDgyiJYjVjkG_Gj8yGVCc`, вкладки «Задачи», «Решения», «Открытые вопросы», «Участники».
- Сервер: `apps-script/Code.gs`, только чтение. Колонки ищутся по заголовкам (`TABS`). Вход по `GROUP_PASSWORD` из свойств скрипта, токен = срок + HMAC, 90 дней. Смена пароля обнуляет входы.
- Почта: `apps-script/Mailer.gs` (previewDigest / sendDigest), читает колонку «Почта» только для отправки, наружу её не отдаёт. Покрыт `tests/mailer.test.mjs`.
- Бот: `apps-script/Bot.gs` (connectMe / connectGroup / testBot / installBotSchedule / stopBot), токен в `TELEGRAM_TOKEN`, чат в `TELEGRAM_CHAT_ID`. Только читает таблицу и пишет в чат. Покрыт `tests/bot.test.mjs`.
- Логика доски без React: `src/lib/board.js` (даты, статусы, зависимости, группировки) — покрыта `tests/board.test.mjs`.

## Жёсткие правила

- Репозиторий публичный. Никаких данных проекта, имён из таблицы, телефонов, почт, паролей, URL таблицы с правами в коде, тестах и коммитах. Тестовые данные — только вымышленные.
- `local/` в .gitignore: там выгрузка настоящей таблицы для локальной проверки.
- Колонка «Почта» не должна попадать в ответ API ни при каких правках. «Контакт» (телефон) и «Telegram» отдаются только после входа — для кнопок связи в карточке человека (решение владельца 10.11.2026).
- Без входа API не отдаёт ничего, кроме `{ok, service}`.
- `public/config.js` содержит только URL `/exec`. Локальный адрес dev-API не коммитить.
